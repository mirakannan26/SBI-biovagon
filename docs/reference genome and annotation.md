# Stage 2: Reference Genome & Annotation

## Tool Options

| Priority | Source |
|----------|--------|
| Recommended | Ensembl |
| Alternative | NCBI RefSeq |
| Alternative | UCSC Genome Browser |

> **Note:** The genome FASTA and the GTF/GFF annotation file must be obtained from the **same source** and the **same assembly version**.

## Procedure

1. In Galaxy, navigate to **GET DATA → Ensembl**.
2. Search for your identified organism.
3. Download the **genome FASTA**.
4. Download the corresponding **GTF annotation**.
5. Record the assembly name and annotation format used.
